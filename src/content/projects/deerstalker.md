# Deerstalker

A 3D online multiplayer brawler game developed as part of CSE 125 at UC San Diego. This capstone project demonstrates advanced game development, network programming, and collaborative software engineering.

## Demo

Check out the [video demonstration on YouTube](https://www.youtube.com/watch?v=hPvb_gEyWpQ) to see the game in action.

## About CSE 125

CSE 125 is a capstone group project course at UC San Diego focused on software system design and implementation. Students work in teams to build a complex software system from scratch, typically a networked 3D game.

## Technical Implementation

- **Network Engine**: Built using Boost Asio for high-performance asynchronous I/O
- **Communication Protocol**: Server-client communication using Google Protocol Buffers for efficient serialization
- **Physics Engine**: Implemented using the Bullet physics library for realistic 3D physics simulation
- **Game Architecture**: Custom game engine with full multiplayer support

## Features

- Real-time multiplayer combat mechanics
- 3D graphics and physics simulation
- Client-server network architecture
- Low-latency game state synchronization
- Collaborative team development with version control
