# Abstract

This paper presents a domain-specific language (DSL) for expressing and working with garbled circuits, a fundamental cryptographic primitive for secure multi-party computation.

## Key Contributions

- Novel DSL design for garbled circuit construction
- Improved ergonomics for secure computation programming
- Performance optimizations
